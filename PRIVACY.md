# Privacy Policy — Monumen MCP Connector

**Last updated:** November 2026

## 1. Overview
Monumen MCP Connector is a private, internal automation tool built exclusively for Monumen. It is not offered to the public or external third-party users.

## 2. Data Collection & Usage
- **No Third-Party Data:** This application only accesses the authorized Monumen account via official API credentials.
- **No Storage or Sharing:** No personal data, analytics, or user information is collected, stored in external databases, sold, or shared with third parties.
- **Security:** API tokens are stored strictly as encrypted environment variables on the host server.

## 3. Contact
For questions regarding this internal tool, please contact the repository owner via GitHub.
